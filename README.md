# 💊 MediTrack

A web-based medication management application built with **Next.js**, designed to help users organize and keep track of their medicines in one place.

## ✨ Features

* 💊 Manage medication information
* 📋 Organize medicines in a simple interface
* 🔎 Quickly view medication-related information
* 📱 Responsive web interface
* ⚡ Fast and modern Next.js application

## 🛠️ Tech Stack

* **Next.js**
* **React**
* **TypeScript**
* **JavaScript**
* **CSS**
* **Vercel** — deployment

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Aaryan030207/MediTrack.git
```

### 2. Navigate to the project

```bash
cd MediTrack
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open **http://localhost:3000** in your browser.
